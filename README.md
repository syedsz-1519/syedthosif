# Syed Thousif — Professional Portfolio

> Corporate Editorial style professional portfolio for Syed Thousif (Project Management, IT, and Sales Leader).

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom editorial typographic scales
- **Typography**: Newsreader (Editorial Serif) + Inter (Clean Sans)
- **Icons**: Lucide React
- **Animations**: Motion (`motion/react`)
- **Theme**: Corporate Editorial Light & Obsidian High-Contrast Dark

## Features
- **Editorial Hero**: Desaturated executive office background with gradient overlay mask, dynamic subtitle cycling, location pill, and key metric strip.
- **Biographical & KPI About Section**: Highlighting M.S. in IT PM, 70%+ sales overachievement, and community volunteering.
- **Vertical Experience Timeline**: Pioneer Solutions (Remote GA), Apple (Exceeded targets by 70%, CRM excellence), Samsung Electronics (Experience Consultant).
- **Featured Case Study**: Structured Problem &rarr; Approach &rarr; Tools &rarr; Outcome framework for *Data Analysis for Marketing Campaign Effectiveness*.
- **Competency Matrix**: Grouped skills pills across Project Management, IT & Governance, and Sales Strategy with interactive filters.
- **Academic Credentials**: Indiana Wesleyan University (3.8 GPA) and Osmania University (7.0/10).
- **Interactive Executive Resume Modal**: Full printable and copyable document view.
- **Executive Contact Band**: High-contrast dark closure section with email copy toast, LinkedIn connection, and message preparer.

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## Vercel Deployment

1. Push code to your GitHub / GitLab repository.
2. Import repository into [Vercel](https://vercel.com).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
